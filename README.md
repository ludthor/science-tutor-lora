# Science Tutor LoRA

A Python learning project exploring whether a LoRA adapter can improve a small
language model's answers and explanations for school science questions.

The project will compare prompting baselines with a fine-tuned model and report
answer quality alongside training cost. Development follows Gitflow; `main`
contains released work and `develop` integrates features.

Status: repository initialized. No training runs or performance claims yet.
